# RBLAB 98

PC-98風のレトロな画面と、気分に合わせて選べる3つのテーマを楽しめる個人サイトです。

**サイトを見る:** [ringobouya.github.io](https://ringobouya.github.io/)

## METEOR CATCHER

画面右上のミニゲームです。左右に移動して、落ちてくる隕石をキャッチします。

- `START` で開始
- 左右の矢印キー、`A` / `D` キー、画面下の左右ボタンで移動
- 10個キャッチするとクリア、3回取り逃すとゲームオーバー
- `Escape` または `END` で途中終了

### ゲーム音声

音楽と効果音は、外部の音声ファイルや音声ライブラリを使わず、ブラウザー標準の **Web Audio API** で合成しています。実装は `index.html` 内のゲーム用JavaScriptに含まれています。

- `AudioContext`、発振器（`OscillatorNode`）、ゲイン（`GainNode`）を使い、矩形波・三角波などの音を組み合わせてBGMと短い効果音を作ります。
- BGMはタイトル、開始待ち、プレイ中、終了、クリア、ゲームオーバーごとに音程の並びを切り替えて、一定間隔で再生します。
- ボタン、移動、キャッチ、開始、終了などの効果音は発振器で作ります。取り逃し音はノイズと低い音を重ねた爆発風の音です。
- BGMと効果音は別々のゲインで音量を制御し、`♪ READY` / `♪ ON` / `♪ OFF` ボタンで再生・消音を切り替えます。
- ブラウザーの自動再生制限に合わせ、音声コンテキストはユーザーが音声ボタンまたはSTARTを操作した後に有効化します。

そのため、追加の音声アセットのダウンロードは不要です。Web Audio APIに対応しない環境では音が出ないことがありますが、ゲーム自体は遊べます。

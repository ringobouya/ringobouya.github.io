# RBLAB 98

PC-98風のレトロな画面と、気分に合わせて選べる3つのテーマを楽しめる個人サイトです。

**サイトを見る:** [ringobouya.github.io](https://ringobouya.github.io/)

## METEOR CATCHER

画面右上のミニゲームです。左右に移動して、落ちてくる隕石をキャッチします。

- `START` で開始
- 左右の矢印キー、`A` / `D` キー、画面下の左右ボタンで移動
- 10個キャッチするとクリア、3回取り逃すとゲームオーバー
- `Escape` または画面右上の `ESC QUIT` で途中終了

### サウンド

音声は初期状態でOFFです。ゲーム画面左上の `♪ OFF` を押すとBGMと効果音がONになり、もう一度押すと消音します。STARTを押しただけでは音は鳴りません。
